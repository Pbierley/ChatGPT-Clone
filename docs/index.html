Features

🔐

User Accounts & Auth

Register and log in with email and password. JWT tokens secure every API request. Passwords hashed with bcrypt.

☁️

Cross-Device Cloud Sync

Conversations persist to MongoDB Atlas. Log in from any device and your full history is there.

🧠

Model Selection

Choose GPT-4o mini, GPT-4o, GPT-4.1, or GPT-3.5 Turbo per conversation. Selection is remembered.

🎭

Custom AI Persona

Set a system prompt per conversation to give the AI a specific role or personality that persists throughout.

🔍

Conversation Search

Real-time sidebar search filters conversations by message content as you type.

📎

File Upload & Summarization

Attach a PDF or TXT file. The AI reads the full document and answers your questions about it.

🎤

Voice Input

Speak your message. Transcription appears in real time using the browser's built-in Speech Recognition API.

🔊

Voice Output

Click the speaker on any AI message to have it read aloud. Click again to stop.

🔒

Secure API Proxy

OpenAI API key lives only on the server. It is never sent to the browser or bundled in client code.
